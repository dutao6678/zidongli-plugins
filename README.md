插件源：`https://raw.githubusercontent.com/dutao6678/zidongli-plugins/main/packages.plist`

在Glyphs设置→插件／Addons的备选插件源中加入上述清单地址，再从窗口→插件管理器安装／更新“字动力 · 矢量批量导入”，完全退出并重启Glyphs。不同语言／Glyphs小版本设置名称可能不同。不要把仓库首页或ZIP地址填成清单地址。

也可解压客户ZIP，按指南双击插件包或拖到Glyphs应用图标安装；若无安装确认，完全退出Glyphs后将完整插件包放到`~/Library/Application Support/Glyphs 3/Plugins/`。保持一份安装，避免旧手工包掩盖管理器版本。授权与工程保存在包外，正常更新无需重新激活。

菜单入口：Glyphs“编辑 → 字动力 · 矢量批量导入”。面板“帮助 → 授权与激活…”复制机器码给作者，导入收到的.svglicense。续期在原窗口导入，无需重装。
