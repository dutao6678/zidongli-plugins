备选插件源：`https://raw.githubusercontent.com/dutao6678/zidongli-plugins/main/packages.plist`

在Glyphs设置“插件 → 备选插件库”添加源地址，一行一个；在“窗口 → 插件管理器”搜索“字动力”，安装后完全退出并重启Glyphs；已安装插件由管理器自动更新，需立即强制更新时可在管理器移除本插件后重新安装并重启（先保存工程和字体，不删除包外数据）。不要把整个仓库的Code ZIP当作插件安装。手动安装请解压客户ZIP，按指南安装完整.glyphsPlugin；只保留一个入口。

从Glyphs“编辑 → 字动力 · 矢量批量导入”打开，激活位于面板“帮助 → 授权与激活…”。复制机器码交给作者，导入设备授权文件。原授权与用户数据保存在插件包外；正常升级不要求重新激活，期限和永久属性不重置。未激活/到期仍可查看、保存及必要恢复，只限制新写入。不要分享GitHub凭据或作者私人签发工具。

## 支持边界
仅本机Apple Silicon/arm64、macOS26.1、Glyphs3.5 build3532、Python3.11.9/PyObjC11.1实测；Intel、第二台Mac、其他系统组合未验收。ad hoc签名，未Developer ID签名或公证，不要求关闭系统安全功能。兼容环境只需按指南一次性准备/明确启用，普通插件更新不重做。

SVG、EPS和矢量PDF严格一页一字/一页一素材，不识别或切分页内文字。未支持的描边效果/蒙版等明确拒绝，不是完整Illustrator兼容。原生、统一画布和适配模式保留。多文档独立面板不是后台并行Glyphs写入；同步核验/备份可能短暂停顿。Glyphs原生撤销按逐字形/编辑视图范围，不承诺整批一次⌘Z；专用恢复保留后续编辑冲突保护。
