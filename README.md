## 安装与授权
首次先核对兼容运行环境。解压客户ZIP，双击完整插件包或拖到Glyphs应用图标安装，退出并重启。若没有安装提示，按指南使用Plugins文件夹安装，避免保留两份相同插件。

入口：Glyphs菜单“编辑 → 字动力 · 矢量批量导入”。激活：面板内“文件 → 授权与激活…”，复制机器码给作者，导入作者签发的设备授权文件。续期在同一面板导入，无需重装。未激活/到期仍可查看、保存工程和必要恢复，限制新的写入。不要分享作者的GitHub凭据。

## 实际支持范围与限制
仅本机Apple Silicon/arm64、macOS26.1、Glyphs3.5 build3532、Python3.11.9/PyObjC11.1完成验证；Intel、第二台Mac、全新用户、其他系统/宿主组合未验收。代码签名为ad hoc，未Developer ID签名或公证。

支持SVG、EPS、矢量PDF；PDF严格一页一份素材，不识别或切分页内文字。超出解析能力的输入明确提示，不代表完整支持所有导出特性。字体原生撤销按既有逐字形范围，不宣称整批一次⌘Z；保留专用恢复及冲突检查。先用字体副本操作，重要资料另行备份。
