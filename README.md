# 字动力 · 矢量批量导入

RC39内测版，建议使用字体副本测试，重要操作前保存备份。

版本 **1.0.0-rc39 / build10039**。支持范围、安装激活和限制见本目录中文说明。本机验证 Apple Silicon / macOS26.1 / Glyphs3.5(3532) / Python3.11.9 + PyObjC11.1；Intel及其他组合未验证。不是正式稳定版。

## 安装及更新
在 Glyphs 设置的“插件 → 备选插件库”中添加源地址（一行一个）：
`https://raw.githubusercontent.com/dutao6678/zidongli-plugins/main/packages.plist`

重开插件管理器，搜索“字动力”，安装/更新后完全退出并重新启动Glyphs。“编辑 → 字动力 · 矢量批量导入”打开。授权和工程存于包外，正常升级无需重新激活。若管理器未提供更新按钮，可保存工作后在管理器移除本插件、再安装并重启；不要删除用户数据目录。

## 本版重点
- Illustrator存储为PDF兼容；多页PDF一页一字/一份素材，不识别或切分一页多字。
- 无固定单批项数上限，保留分段预检、备份、取消和恢复。
- 简体中文、繁體中文、English、日本語、한국어；帮助 → 界面语言。
- 已验证的标准描边在临时副本展开，保留可见端帽/转角/虚线/变换；源文件不变。复杂画笔、部分PDF表单/透明度、未知EPS操作等并非全部支持；不能可靠处理时明确报错。

使用原生、手动画布或适配目标模式，预览与写入使用同一候选。追加保留已有部件。Glyphs字体撤销按宿主逐字形范围，不承诺整批一次⌘Z；专用恢复保留后续编辑冲突检查。未激活/到期不影响已有工程查看、保存及必要恢复。

客户仓库不包含私人签发工具和密钥。ad hoc签名，未Apple公证；不要关闭系统安全功能。软件及第三方许可见插件包内说明。
